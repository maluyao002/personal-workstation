# 个人工作站 · 三种原型方向

本轮只验证网页结构、视觉语言和关键交互。全部内容为演示数据，不连接账户、不发送邮件、不写入日历、不调用 AI、不产生费用。优先使用本地字体，不加载第三方图片或脚本。

## A 决策工作台

参考 Mandate 的深浅对比、顶部胶囊导航和待审批区，将首页组织为“先理解今天，再处理需要我确认的事项”。

- 颜色：雾灰 `#E7EBEC`、纸白 `#FFFFFF`、夜墨 `#171C25`、紫蓝 `#5547C7`、次级灰 `#66727C`、警示棕 `#A5512A`。
- 字体：Avenir Next / PingFang SC 为界面与标题，Georgia 仅用于大号日期；左对齐。
- 主体：深色今日计划与时间分配占左侧，白色确认队列占右侧；下方消息变化与后台状态形成横向阅读流。
- 特征：确认队列是主要操作入口，证据、建议与确认结果分开；圆形图表达时间容量，不绘制无意义的 AI 网络。

```text
品牌          [ 今日 | 项目 | 动态 ]          问工作站
┌─────────────────────────────┬──────────────────┐
│ 今日计划 / 时间容量          │ 等待你确认        │
│ 已确认安排 + 可用时间        │ 任务 / 邮件 / 日历 │
├─────────────────────────────┼──────────────────┤
│ 今天有哪些变化               │ 数据与运行状态     │
└─────────────────────────────┴──────────────────┘
```

## B 今日手册

参考 Oriel 的浅紫底、纤细侧栏、蓝色信息强调与右侧解释栏；将金融仪表盘改为全天生活的时间轴。

- 颜色：淡紫灰 `#EFF0F6`、白 `#FFFFFF`、深蓝黑 `#19203B`、电蓝 `#384DE3`、灰紫 `#737B94`、叶绿 `#567146`。
- 字体：Georgia / Songti SC 用于欢迎语与阅读标题，Avenir Next / PingFang SC 用于正文与数据；正文左对齐。
- 主体：窄侧导航，中央以时间轴组织今日安排，右侧是每日简报；项目与投资通过导航切换为完整内容视图。
- 特征：以一天的可用时间为核心，金融只占适当篇幅，不将局部账户总额误作全部财富。

```text
│导航│ 早上好，演示用户                     搜索 / 问工作站
│    │ ┌─────────────────────────┬──────────────────┐
│今天│ │ 今天的时间与任务          │ 每日简报         │
│项目│ │ 时间轴 / 计划建议          │ 新闻与持仓关联    │
│投资│ │                          │ 深入阅读         │
│设置│ └─────────────────────────┴──────────────────┘
```

## C 信号观察室

参考 Tokenex 的深色、留白、浅黄色操作和粒子图形的空间感，改为可工作的“变化 → 证据 → 行动”三栏界面。

- 颜色：炭灰 `#252629`、深灰 `#303136`、米白 `#F3F2EA`、柔黄 `#E6D995`、中灰 `#AEAFB6`、灰紫 `#B4A7C6`。
- 字体：Avenir Next Condensed / PingFang SC 用于标题，Avenir Next / PingFang SC 用于正文；左对齐。
- 主体：左侧领域与变化列表，中间主阅读面，右侧关联日程、持仓和下一步行动；顶部保留今日待办入口。
- 特征：先读变化，再核对来源，再收进任务箱；大图只为主题阅读服务，粒子图仅作为可选图片占位。

```text
品牌          [ 信号 | 今日 | 项目 ]          站内提醒 / 问工作站
┌───────────────┬──────────────────────────┬────────────────┐
│ 领域 / 变化流 │ 选中内容的分析与来源      │ 与我的关联      │
│ 新增 / 更正   │ 可选主题图片占位          │ 下一步 / 待确认 │
└───────────────┴──────────────────────────┴────────────────┘
```

## 建造前自评与修订

三版不使用同一组卡片换色。A 聚焦确认，B 聚焦时间，C 聚焦阅读。取消参考中的营销大标题、模拟净资产总额和抽象风险球：这些会把个人工作站误导成销售页或金融终端。三个版本都提供今日、项目、新闻/投资、权限与运行状态入口，但顺序与视觉权重不同。

图像只保留在编辑性内容和可选个人封面中；关键指标、来源、状态和操作不能依赖图片。移动端按主要任务顺序单列重排，保留简报、日程、待办、简单确认与追问。

## 所有版本共有的边界

- 醒目标明演示数据，确认操作只改变本页演示状态。
- 接受任务、确认日计划、执行日历/邮件操作分别确认。
- 财务只读；银行、Drive、知识库、Codex 项目观察不加入。
- 已确认安排不被刷新覆盖；工作邮件正文跨领域使用仍需单独授权。
- 只展示站内提醒；数据时间、检查时间、缺失账户与失败可见。
- 图片占位说明题材、比例和用途，不盗用参考作品或伪装成真实数据。
