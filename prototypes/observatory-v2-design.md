# 信号观察室 v2：围绕研究主题组织

用户已选择 C 为主方向。研究跟踪同时覆盖投资标的与 AI、宏观、地缘政治长期议题，以主题组织、关联标的。本轮仅更新交互原型，沿用本地演示数据和图片占位。

## 五个入口的分工

| 入口 | 首要内容 | 关键连接 |
|---|---|---|
| 今日动态 | 自上次查看以来，与自己相关的变化、今日简报及待处理项 | 到新闻原文、研究主题、投资标的、日程待办 |
| 日程和待办 | 日历安排、任务收件箱、已接受任务、工作/学习/家庭项目 | 任务保留新闻/研究来源；接受任务和确认计划分开 |
| 新闻热点 | 按事件聚合的新闻、不同领域筛选、来源与新增/更正 | 事件关联一个或多个研究主题及标的 |
| 投资观察 | 只读持仓与关注标的、变化与风险问题、账户覆盖 | 从标的进入相关主题；不会提供交易按钮 |
| 研究跟踪 | 主题列表、核心问题、当前判断、新证据、待验证问题和下一步 | 一个主题关联多个标的；一个标的关联多个主题；可生成待整理任务 |

“今日动态”是个人化的变化摘要，“新闻热点”是按事件阅读；“研究跟踪”跨越单条新闻，保留判断和证据的演进。研究主题不是一个必须完成的项目，项目是有明确结果的行动集合。

## 视觉与结构

沿用炭灰 `#252629`、内容灰 `#303136`、米白 `#F3F2EA`、柔黄 `#E6D995`、中灰 `#AEAFB6`、灰紫 `#B4A7C6`。Avenir Next / PingFang SC 为正文，Avenir Next Condensed / PingFang SC 为标题。正文左对齐，时间与来源使用较小但清晰可读的层级。

五个入口改为常驻左侧导航，避免顶部胶囊拥挤；保留 C 的安静深色与宽阅读面。首页用不等宽的变化摘要和今日安排侧栏；研究与新闻使用主题/事件列表、阅读正文、关联上下文。投资使用标的列表与解释，不以不完整总资产作为首页大数字。手机将导航收为易于点击的菜单，正文单列，保留五个入口完整名称。

自评修订：不把五个入口做成五份相同卡片，也不把研究主题变成只有标题的收藏夹。可核对的证据变化和跨页面关联是主体验；图片仍只用于科技专题阅读，预留 16:7 暗色计算设施图。宏观/地缘政治页面优先文字与来源，无需装饰图。

## 研究页细化（2026-10-12）

本轮沿用现有字体和六色系统，集中改善研究正文。所有内容左对齐；标题 32px、分区 21px、正文 14px，读段控制在约 60–75 个汉字宽度以内。柔黄强调本次变化，灰紫标记更正与条件收窄，普通灰用于判断未变。状态同时用文字说明。

```text
研究跟踪 / 主题导航（主题显示变化数量与判断状态）
主题问题 + 本次比较区间 + 最近检查与覆盖
┌ 本轮结论：判断维持 / 适用范围收窄 / 判断调整 ┐
│ 上次判断                 当前判断             │
│ 改变原因 + 保留意见 + 对判断的把握             │
├ 新变化：证据事实 → 对判断的影响 → 来源         │
├ 待验证：问题 / 进度 / 缺少证据 / 改变判断条件   │
├ 标的影响：传导路径 / 方向与条件 / 时间 / 未知   │
└ 判断历史（可展开）+ 行动进入待整理箱             ┘
```

桌面以宽阅读正文加窄侧栏展示标的影响和建议行动；中等宽度和手机将侧栏置于正文之后。主题列表保留轻量选择；提供四个章节按钮，点击滚动到对应内容，不替换顶层页面路由。比较区间使用明确的演示日期，不假装记录过用户真实阅读时间。

自评：不堆砌新闻卡片或以装饰图占据首屏。最突出的视觉是判断前后对照，使“新闻变了、结论未必变”一眼可见；图片位置移入收起的专题配图说明，保留 16:7 算力设施摄影建议。三个主题都提供完整且不同的判断状态与验证内容，投资影响明确为有条件的演示分析，无交易操作。

验证顺序：先核对三主题内容与来源对应，再验证章节定位、判断历史展开、主题与标的往返、研究行动进入待整理箱；最后检查桌面和手机布局及现有状态测试。

## 原型边界

示例主题：AI 推理成本、利率与资产定价、中美科技政策。相关标的可用 NVDA、MSFT、TLT、黄金等符号，但所有价格、持仓、事件与研究判断明确为虚构演示，不是实时行情或投资建议。Robinhood 与 Charles Schwab 只读，覆盖缺失明确可见。银行、Drive、知识库及 Codex 项目观察不加入。

主题与标的关联使用已批准的新闻/投资授权；研究任务保留来源并先入待整理箱，用户选择项目后接受，不自动改变已确认日计划。工作邮件正文跨领域使用仍需单独授权。界面操作只保存在演示页面，不调用外部账户、AI 或付费服务。
